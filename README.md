# Garten24h

SEO-starker Relaunch von Garten24h für Bewässerungsanlagen, Poolbau und das Ladengeschäft in Berlin und Brandenburg.

## Veröffentlichung

Jede Änderung am Branch `main` veröffentlicht den fertigen Inhalt aus `dist/` automatisch per SFTP auf dem hinterlegten Hetzner-Webspace.

Benötigte GitHub-Actions-Secrets:

- `HETZNER_HOST`
- `HETZNER_USER`
- `HETZNER_PASSWORD`
- `HETZNER_PORT`
